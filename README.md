## 06 / HOW I WORK WITH AI

I use AI as a learning and development partner — not as a substitute for understanding the code.

My preferred workflow is:

1. **Frame the problem:** Define users, constraints, success criteria, and the smallest useful scope.
2. **Plan the system:** Sketch components, API contracts, data models, and important trade-offs.
3. **Build incrementally:** Work in small slices that can be run and reviewed.
4. **Debug with evidence:** Reproduce errors, inspect logs, isolate causes, and verify fixes.
5. **Test and review:** Check edge cases, permissions, validation, and failure paths.
6. **Explain the result:** Document how it works, what remains incomplete, and what I would improve next.
